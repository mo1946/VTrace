## 7. 问题清单

以下仅记录，**没有自动修复**。P0 为核心阻塞，P1 为重要问题，P2 为一般展示／体验问题。

### P0：本次样本未发现核心流程阻塞

真实上传／续传、导入、转写、音频下载、分析、恢复和追问均跑通。该结论只适用于本地 Python 模式及本轮样本，不覆盖未验证的生产环境。

### P1-01：抽屉缺少模态焦点管理，隐藏后仍可被聚焦

- **复现**：打开 Agent，使用 Tab 遍历；从输入框继续切换会跳到遮罩后的退出按钮。按 Escape 不会关闭。按钮关闭后，抽屉内部按钮仍可获得焦点。
- **实测**：关闭后的关闭按钮仍为 `tabIndex=0`；1440px 视口中聚焦后 x 约 2826px，位于屏幕外；抽屉无 `role="dialog"`、`aria-modal` 或标题关联。
- **影响**：键盘用户可能进入不可见控件，背景内容可被误操作；辅助技术难以识别当前模态上下文。
- **位置**：`client/src/App.vue:265`、`client/src/App.vue:1146`。
- **建议**：打开时移动焦点、限制焦点范围、支持 Escape、关闭时恢复触发位置；关闭后使内部控件不可聚焦，补充适用的 dialog 语义。需用户确认后实施。

### P1-02：本地上传入口无法通过 Tab 到达

- **复现**：关闭抽屉，切换到本地文件；从来源切换按钮开始按 Tab，焦点跳过可见的上传区域。
- **原因与证据**：文件 input 为 `display:none`；可见的 `label[for="file-input"]` 为 `tabIndex=-1`，没有替代的键盘可操作入口；实际 18 步 Tab 路径未到达上传控件。
- **影响**：仅使用键盘的用户无法从当前本地上传区域选择视频。
- **建议**：提供可聚焦、可用 Enter／Space 激活的文件选择入口，并保留原有文件选择事件、拖放与续传行为。需用户确认后实施。

### P2-01：真实 LangGraph 执行步数显示为“执行 / 步”

- **复现**：在当前 structured 分析路径完成真实报告后，展开执行详情；框架、意图和工具列表有内容，但执行步数为空。
- **原因与证据**：前端无条件使用 `graph.steps` 和 `graph.maxSteps`；实际 structured 图结果包含 framework、intent、nodes、modelCalls 等字段，没有这两个步数字段。真实截图已复现，不是单纯展示数据推断。
- **影响**：执行详情看起来不完整；不阻止分析、报告和追问。
- **位置**：`client/src/App.vue:339`。
- **建议**：仅在现有返回字段有效时展示该步数项，缺失时隐藏或使用已有真实状态信息；不要伪造数值或为此修改后端契约。需用户确认后实施。

### P2-02：手机端极长文件名占用过高的抽屉头部

- **复现**：375×812，给 Agent 标题使用约 150 字文件名；头部增高到 265px。
- **影响**：仍无溢出，追问区可见，但正文剩余 398px，长报告阅读空间被挤压。普通文件名未出现此问题。
- **位置**：`client/src/agent-workspace.css:26`。
- **建议**：限制标题展示行数，保留查看全名的可访问方式；保持顶部与底部固定结构。需用户确认后实施。

### 环境和维护观察（不等同于当前失败）

- 缺少 ffmpeg CLI 时，BV 首选路径有错误日志，现有降级路径本轮成功；演示时应准备已验证 BV，并区分前置错误与最终状态。
- 依赖警告和样式覆盖较多；本轮不更新依赖、不清理 CSS。
- 本地 `.env.local` 被 Git 忽略。复制项目或部署时必须按 README 配置分析后端；当前可用的 Python 模式不代表未启动的 Java 服务自动可用。

## 9. 最终结论与演示建议

**当前版本可以用于经过准备的本地桌面演示和求职展示，结论为“有条件可演示”，不是“正式全项验收通过”。** 本轮没有发现前几轮 UI 优化破坏已测核心业务链路的证据：真实上传续传、音频下载、文字提取、BV 导入、AI 任务、报告恢复和两轮追问均可运行，桌面／平板／手机主要布局稳定。
